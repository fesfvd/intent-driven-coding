# Host Acceptance Fixture Professional Squads

The router is the control plane and does not count as a Squad member. It uses the smallest registered route supported by current source and test evidence.

## Registered Squads

### Bug Resolution

| Field | Definition |
|---|---|
| Members | `debug` -> `verify` |
| Handoff | Diagnosis artifact -> focused command evidence |
| Permission | Local edits remain confirmation-gated; external actions are unauthorized |

### Cross-Layer Change

| Field | Definition |
|---|---|
| Members | `architecture` -> `code-review` -> `verify` |
| Handoff | Impact contract -> review findings -> focused command evidence |
| Permission | Local edits remain confirmation-gated; external actions are unauthorized |

### Release Boundary

| Field | Definition |
|---|---|
| Members | `code-review` -> `verify` -> `project-specific-release` |
| Handoff | Findings -> verification evidence -> explicit named-effect decision |
| Permission | A local passing test never authorizes a commit, push, deployment, or release |

## Direct Work

Local copy corrections use main-Agent implementation plus `verify`; they are not a ceremonial Squad.
