# Plans

This directory records the current state and staged development plans for Intent-Driven Coding.

Plans are commitments to investigate or build only after their stated entry criteria are met. They do not override the framework's existing safety rules or grant permission to perform external actions.

## Files

- `CURRENT_STATE.md`: What is implemented, what is verified, and what remains unproven.
- `ROADMAP.md`: Ordered phases, exit criteria, and explicit non-goals.
- `PROJECT_PROGRESS.md`: Chronological decisions, implementation milestones, and evidence events for this project itself.

## Planning Rules

- Keep phases outcome-based and evidence-gated.
- Separate implemented capability from design intent and unverified claims.
- Prefer a small experiment over a new platform layer.
- Update the relevant phase after a real acceptance run, user study, or implementation decision.
